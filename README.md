# Hi, I'm Jakub Juhas

I'm a software engineer from Slovakia, based in Kosice. I build product interfaces, developer tooling, and AI-native workflows with TypeScript, React, Angular, Supabase/Postgres, MCP, agent skills, and eval-first reliability loops.

Right now I am especially interested in tools that help developers and agents work with real systems safely: typed action surfaces, confirmation gates, RAG over product knowledge, testable agent behavior, and clean abstractions around AI workflows.

[LinkedIn](https://www.linkedin.com/in/jakub-juh%C3%A1s-98b04834/) · [X / Twitter](https://twitter.com/JakubJuhs) · [Interactive CV](https://juhas96.github.io/)

## Focus

- AI tooling for developers and agents: MCP, agent skills, app actions, assistant workflows, and tool orchestration
- TypeScript platform work: npm packages, ESM, browser/runtime compatibility, React, Angular, and Node.js
- Eval-first AI development: deterministic checks, LLM-as-judge flows, smoke evals, and feedback loops
- Supabase/Postgres apps: migrations, generated TypeScript database types, auth, local development, and typed query layers
- Product engineering: reliable interfaces, testing discipline, observability, and developer experience
